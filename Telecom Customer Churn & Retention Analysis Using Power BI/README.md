# Telecom Customer Churn & Retention Analysis Using Power BI

## 1. Project Overview

This project focuses on analysing customer churn and retention for a telecommunications company using Power BI.

The main objective is to understand customer behaviour, identify churn patterns, analyse service usage, and provide insights that can help the company reduce customer loss and improve customer retention.

## Project Objectives

- Analyse the total number of customers.
- Identify churned and retained customers.
- Calculate customer churn and retention rates.
- Understand customer behaviour and service usage.
- Analyse factors contributing to customer churn.
- Provide meaningful business insights through interactive dashboards.

## Tools & Technologies Used

- Power BI Desktop - Dashboard development and data visualization
- Power Query - Data cleaning and transformation
- DAX (Data Analysis Expressions) - Calculated measures and KPIs
- Microsoft Excel / CSV (Dataset) - Data handling and analysis
